# flashcards-ios

Flashcards for iOS — an independent Swift/SwiftUI implementation of the same
product as the Android app at `guillermo-rebolledo/argo-flashcards`, built in
Apple's design language rather than as a port of Material You. No shared code.

## Agent skills

### Issue tracker

Issues live in Linear — team `Memoji inc` (`MEM`), project `flashcards-ios` —
via the Linear MCP tools. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name; all exist
as team labels in Linear. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root, with ADRs
mirrored against the Android repo. See `docs/agents/domain.md`.
